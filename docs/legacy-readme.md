# 多来源文献相关性筛选工具

这是一个 Windows 桌面工具。首页左侧管理项目，各项目独立保存题录、去重核查、检索式、API 缓存和导出。右侧工作区自动识别来源、导入题录并按题名排序；操作者选择去重模式、逐组核查，最后统一去重。之后默认由 TypeSafe Jev 完成全量初筛，再由 DeepSeek 复核风险边界，也可单独选择任一模型。

1.22.0：参考 Apple Human Interface Guidelines 的视觉层级、对齐、留白和操作标签原则，统一浅色背景、淡蓝绿主操作、深色正文与低干扰次要控件。项目侧栏将新建、重命名和删除分出清楚层级；文献文件操作拆成导入与查看两行；导入预览把编辑、检索、导入导出和导出范围分组，并缩短状态摘要。增大通用控件字号与点击区域，在 1050×680 主窗口、820×520 导入预览和多档系统缩放下核对布局。

1.21.3：新建与重命名项目弹窗不再使用固定 430×245 像素，窗口会按当前 DPI 下控件实际尺寸扩展，并限制在可用屏幕范围内；按钮加宽，避免高缩放屏幕文字被挤压。已在 Tk 100%、150%、200%、250% 缩放下检查按钮完整显示。

1.21.2：关键词自动合并默认使用首字母大写、其余小写的保留词，优先采用无连字符写法；只有数字标识中的连字符（如 IL-6）保留。DeepSeek 关键词建议也统一此格式，提示词明确禁止把上位词与下位词、核心词与限定短语合并，并在导入时拦截可由词形判断的范围变化。既有可疑 DeepSeek 规则不会被自动删除，在导入预览中以“待核查”提示；可用“刷新关键词保留词”更新既有 AI 规则的格式。

1.21.1：修复 WoS 单条 C1 字段包含多组作者地址时，国家合并只处理末组的问题。项目中已保存的国家规则会应用到每组地址；合并预览的原始出现次数、VOS 国家节点和导出题录同步使用完整地址。已保存的旧 VOS 图谱是快照，更新后需点“生成并打开图谱”重新创建。

1.21.0：VOS 图谱新增期刊、被引作者、被引期刊、被引文章。期刊节点以共同引用的参考文献建立文献耦合连线；三种被引对象按同篇题录中的 CR 引文建立共被引连线。缺少 SO 或 CR、阈值下节点不足、无可连接节点时均在界面显示具体原因。被引对象的“引用次数”是当前项目题录集中的被引次数；被引文章按 CR 引文条目显示，原始题录未提供文章题名时不会补造。

1.20.0：基础导出与 AI 筛选结果 TXT 统一采用参考 WoS 纯文本结构：标准页眉直接接首条 PT、作者与引用使用续行、关键词用分号分隔，UTF-8 无 BOM 且换行统一为 LF。文献工作区新增“仅转换格式并合并…”独立窗口，多个文件按清单顺序转换到一个 WoS 兼容 TXT，保留重复题录和原始词语，不执行任何项目去重或词汇合并。导入预览增加“规则归属”“当前文件”列；导出合并 TXT 时可选全部合并词或仅导出当前文件中出现的合并词。旧项目首次升级时，历史归属以当时的共享目录为基准。Excel 导出改为直接定位内置模块，无需在临时目录建立 Junction。

1.19.4：国家、机构、作者、期刊的已应用合并自动写入全局目录；新项目以及旧项目之后新增文件时会自动加载最新目录。修复旧项目导入时可能误删其他项目共享规则的问题，只有在当前项目明确删除的合并项才会从全局目录删除。关键词仍只属于当前项目；手工编辑需点“应用合并到项目”，DeepSeek 有效建议仍自动保存。

1.19.3：文献工作区新增项目级“跳过去重”，跨库题录全部保留，可直接绘图、建立 VOS 节点和导出 TXT；切回原模式恢复去重历史。合并规则应用不再清空去重核查或 AI 历史；匹配字段变化时提示重新核查，AI 输入变化时标记结果需重新分析。关键词规范词刷新仍自动保存。

1.19.2：导入预览的关键词页新增“刷新关键词保留词”。点击后重算已有自动合并项，整理已保存的 DeepSeek 规范词为首字母大写、其余小写；等价词形优先采用无连字符写法，人工设置的保留词保持原样。已完成基础去重的项目会自动保存并更新题录与 VOS 节点预览；已打开的 VOS 图需重新生成。

1.19.1：DeepSeek 关键词建议的校验改为增量规则检查；自动合并冲突用分组二分定位，不再对大量建议逐条重扫全部题录。AI 关键词保留词采用首字母大写、其余小写；存在等价无连字符写法时优先选用，既有人工规则保留原样。VOS 编辑模式只允许选择和拖动节点或聚类，标签及连线跟随节点移动，不再单独拖动标签或选中连线。

1.19.0：内置 VOS 网络视图新增“编辑网络图”。支持 Ctrl 多选并拖动节点、锁定节点位置、拖动聚类内部空白处移动整组；重叠区域连续操作时先选节点数最多的聚类，再逐层切换。可手动调整节点颜色、大小、聚类与标签位置，隐藏/恢复节点、连线和标签，并撤销/重做。“聚类等距横排”将各聚类排在等距水平行，每行节点等间距。更改自动写入当前图谱 JSON；编辑模式导出保留独立文字和图形对象的 SVG，以及 PNG。聚类区域的淡色轮廓仅用于操作指引，不包含在导出图中。

1.18.8：VOS 时间视图依据节点平均发文年份的实际分布设置蓝、青、绿、黄渐变色阶，集中年份之间的颜色更容易区分。首次成功选取 VOSviewer 桌面版程序后，路径作为软件全局设置保存，后续项目直接复用。内置 VOS 窗口中布局、聚类及显示参数调整后自动写入全局默认值，新图谱继承最近保存的参数；节点坐标和年份范围仍由各图谱自身决定。

1.18.7：VOS 内置窗口新增“网络视图／时间视图”切换；时间视图复用当前网络的位置、连线和交互，仅将节点按平均发文年份从深蓝绿渐变为亮黄，并随图谱 JSON 保存。左侧项目区新增“删除项目”：确认后从列表移除项目，题录与规则进入本地项目回收目录；原始题录文件和已导出文件不受影响。删除最后一个项目时自动建立新的默认项目。

## 使用

1. 从文献数据库导出完整题录。支持 WoS 标签 TXT、表格 TXT、旧版 XLS、BibTeX、RIS；Scopus RIS、纯文本、BibTeX、CSV；PubMed 完整题录 TXT/NBIB、CSV；ScienceDirect RIS 内容 TXT/RIS；中文数据库 RefWorks TXT。选择文件时不需要指定来源，程序按文件内容识别。
2. 把 Key 文件放在 EXE 或源码项目根目录：Jev 使用 `typesafe_api_key.txt`，DeepSeek 使用 `api_key.txt`；默认混合模式需要两套 Key。每个文件第一行只填写对应 Key，也可分别设置 `TYPESAFE_API_KEY` 或 `DEEPSEEK_API_KEY` 环境变量。
3. 双击 `启动文献筛选工具.bat`。
4. 在左侧新建或选择项目；“删除项目”确认后把项目数据移入本地回收目录，不删除原始题录文件或 output 导出。文献工作区顶部三张数字卡片显示“导入成功”“去重移除”“目前保留”，按项目全部年份统计，且导入成功 = 去重移除 + 目前保留；只计入已应用的去重结果。把题录文件或文件夹拖到右侧工作区，程序立即识别题录；逐文件清单显示文件名、来源、成功/失败数和状态，双击查看完整路径。“各数据库导入情况”显示来源统计。点击“查看题录列表…”会打开独立窗口，题录按题名排序，双击可查看详情。点击“查看导入预览”可按国家、机构、作者、期刊、关键词查看全部合并对和每条题录的字段变更；支持检索、编辑、统一应用及按类别导入/导出双列制表符 TXT 文件。先切换到对应类别，再点“导入当前类别 TXT…”；导入会进入草稿，核查后点“应用合并到项目”。完成当前年份范围的基础去重后，切换到要处理的类别页，再点“DeepSeek 分析当前类别”：程序仅提取该类别的全部不同术语、出现次数与少量上下文并分批发送 DeepSeek，其他四类不会调用；只接纳输入术语之间、且与已有规则不冲突的建议；有效建议会自动保存到当前项目并刷新 VOS 节点预览，合并清单仍可核查和编辑。若作者或期刊合并产生新的重复候选，需先复核去重再生成 VOS 图谱；已经打开的旧图谱文件不会被覆盖，需重新生成。调用需要 `api_key.txt` 或 `DEEPSEEK_API_KEY`，多批调用可能产生 API 费用。国家标准别名及四类非关键词字段的保守写法变体会自动合并；已应用的国家、机构、作者、期刊合并会保存到 `data/shared_vocabulary.json`，供其他项目自动复用，删除或修改后同步更新。关键词仅保留在当前项目，不写入共享目录。英文关键词单复数和空格/连字符变体默认自动合并，也可加载 [词汇规则示例](vocabulary_rules.example.json)。只有合并规则改变去重匹配字段时才需要重新核查；旧项目已有已完成结果时不会仅因切换项目而静默改写这些结果，新增导入文件会读取最新全局目录。
5. 可在文献工作区输入起止年份并点击“应用年份”。列表、去重和基础导出只处理范围内的题录；年份缺失的记录保留。范围外题录仍保存在项目中，切换年份后需要按新范围重新去重。
6. 选择“严格”“宽松”“期刊”或“快速”，点击“查找重复”。核查窗口默认选择 WoS 来源；同来源时优先选择字段较完整的题录。逐组确认后点击“统一去重”。也可点击“一键去重”：自动保留 WoS，遇到同组 DOI 不同则保留全组。去重历史显示每次的候选组数、疑似重复数、确认数和实际排除数；原始题录始终保留。
7. 完成基础去重后，点击“导出基础去重结果…”，在保存对话框中选择地址。默认文件名为 `download_YYMMDDHHmm.txt`，例如 `download_2609270102.txt`；导出当前年份范围内已保留的题录，无需 API Key。
8. 如需 AI 主题筛选，切换到“筛选与导出”，输入原始检索式，选择 AI 后端（默认 `Jev + DeepSeek 复核`），然后开始分析。
9. 在存疑复核窗口中勾选不相关文献；未勾选者默认相关。结果写入程序目录的 `output\YYMMDDHHmm` 文件夹；同一分钟再次导出会加 `_01` 等后缀，避免覆盖。运行日志显示在文献工作区和筛选与导出页下方。
10. “发文趋势与排名”使用已去重题录，无需 API；也可选“AI 筛选相关”。可切换年度趋势、发文与被引排名、关键词排名及不同图型。左侧提供指标、前 N 项、数据库分组、关键词来源、线性/二次/LOESS 拟合、标题、图例、网格、坐标轴、标签、配色和导出尺寸；滚轮可滚动左侧全部选项。右侧用“图表预览 / 绘图数据”标签切换，绘图数据可逐行开关；可拖动图中的标题、图例、坐标文字和数据标签调整位置，PNG 导出沿用调整。无数据的中间年份按零补齐，年份轴按公历年份等距绘制，回归也使用完整年份序列。PNG 与 CSV 均可选路径导出，图表选项按项目保存。WoS/Scopus RIS 的注释被引字段会自动读取；打开旧项目时可从仍可读取的原始文件补回。缺少被引字段的记录会提示覆盖比例，不会被当作 0 次引用。此页不显示运行日志。
11. “VOS 图谱”可选择关键词共现（默认）、作者合作、国家合作或机构合作，并调整最少出现次数和最多节点数。节点清单列出名称、频次、引用次数和 TLS；点击列标题排序，点击首列勾选是否纳入图谱，选择会随项目保存。点击“生成并打开图谱”后，软件从当前项目、当前年份范围的已去重题录建立网络，保存到 `output\YYMMDDHHmm\vos_*.json`，再用内置 VOSviewer Online 交互窗口打开；也可选择已有的 AI 相关题录。窗口顶部“时间视图”按节点平均发文年份从深蓝绿到亮黄着色；“网络视图”恢复聚类颜色，两者沿用相同位置、连线和交互。缺少年份时不能切换时间视图。窗口中的布局、吸引力、斥力和聚类分辨率可调整，图谱会自动保存；顶部可手动保存 JSON、导出 VOS 地图与网络两个制表符文件、保存 PNG 截图。主界面的“打开上次图谱”可继续编辑已保存图谱。需要 VOSviewer Desktop 原生密度视图或 SVG 导出时，点击“VOS 桌面版（原生叠加/密度）”，首次选择 VOSviewer.exe，软件会生成当前图谱并自动交给桌面版打开；此入口需要另装 VOSviewer。机构规则更改后请生成新图谱，已打开的旧窗口不会自动更新。内置窗口需要 Windows WebView2 Runtime。

四个去重预设依据从原 BibNexus 发布前端提取的字段组合：快速＝DOI/数据库标识符，期刊＝题名＋年份＋作者＋期刊，严格＝题名＋年份＋作者＋摘要，宽松＝题名＋年份。比较时忽略大小写、符号和空白；缺少预设必需字段时不产生候选。原版 Rust 匹配函数已编译，无法证明当前候选数量与原版逐条完全一致；人工模式可逐组核查，DOI 不同的组会特别提示。

一键去重使用当前选择的模式，自动应用候选组；DOI 不同的组不会自动移除。建议首次使用宽松模式时先查看候选组，再决定是否使用一键去重。基础导出使用 WoS 风格 TXT；混合来源题录会转换字段，导入 CiteSpace 前建议核对兼容性。

只有 PMID 编号的 TXT 列表会被识别，但不含题名或摘要，不能单独用于主题筛选；请同时导入 PubMed 完整题录 TXT 或 CSV。`.txt` 不代表 WoS：PubMed 和 ScienceDirect 样本也会按内容识别。无法识别的文件会明确报错，不会默默当作 WoS 读取。

## 输出

- `文献筛选结果.xlsx`：筛选总表、相关、不相关、人工复核、去重、失败和运行信息；包含来源数据库、格式、数据库编号。
- `download_relevant_YYMMDDHHmm.txt`：只含最终相关记录。原始 WoS 标签文本在未合并词汇时保留原记录块；其他格式转换为 WOS 风格字段。混合来源导出请在 CiteSpace 中复核字段兼容性。
- `筛选审核日志.jsonl`：API 初筛审计记录。
- `去重日志.csv` 与 `API失败记录.csv`。去重日志只记录人工确认且已统一应用的重复记录。
- 图表 PNG 与绘图数据 CSV：从统一图表工作台保存；默认文件名含 `YYMMDDHHmm` 时间戳，PNG 嵌入所选 DPI。
- `vos_<类型>_YYMMDDHHmm.json`：内置 VOSviewer 的图谱与窗口调整结果；同目录可导出 `*_map.txt` 与 `*_network.txt`，供 VOSviewer Desktop 使用，截图保存为 PNG。
- 词汇合并 TXT：预览窗口可按当前类别导入/导出，或一次导出国家、机构、作者、期刊、关键词五个文件；每行只有“保留词、制表符、合并词”，无表头。支持 UTF-8 和 GB18030 导入；格式错误会整份拒绝，不会只应用部分规则。

## 判定规则

- 检索式是唯一主题依据。
- 摘要缺失不自动进入存疑；题名和关键词明确相关时判为相关。
- 明确命中检索式的排除含义或偏离主题时判为不相关。
- 证据不足、歧义或 API 失败时进入人工复核。
- 发文年份范围支持双边或单边限制。范围外记录不调用 API，并在总表和审核日志中标明；年份缺失或无法识别的记录会保留进入主题筛选。
- Jev 使用高召回筛选策略：原始选择“相关”时直接纳入；只有 Choice 置信度至少 60% 且“不相关”概率至少 75% 时才自动排除。未达到自动排除门槛的记录保守纳入“相关”，不再挤入人工复核；Jev 明确选择“存疑”或 API 最终失败时才进入人工复核。
- DeepSeek 保留原有生成式三分类、文本理由和 max-token 自适应降级流程。
- 默认混合模式先调用 Jev 处理全部记录，只把三类记录交给 DeepSeek：Jev 明确存疑、Jev API 失败、Jev 原始选择不相关但未达到自动排除门槛。DeepSeek 成功时采用复核结论；DeepSeek 失败时保留 Jev 的高召回安全结果。
- 总并发数可设置为 1–32，默认 16。混合模式内部会把 DeepSeek 二级复核并发限制为最多 8，避免提高 Jev 吞吐时同时压垮 DeepSeek；单独 Jev 建议 8–16，单独 DeepSeek 建议 3–8。遇到限流或网络不稳定时可降低总并发。

## 隐私与恢复

- `typesafe_api_key.txt`、`api_key.txt`、缓存、输入数据和输出目录均已加入 `.gitignore`。
- API 请求只发送题名、摘要、关键词、文献类型、年份和 WOS 分类，不发送参考文献或作者单位。
- 每篇完成后立即写入 SQLite 缓存。相同题录、检索式、模型和提示词版本下重跑会复用缓存。
- Jev 不生成长篇文本，审核页和 Excel 显示其分类概率摘要；选择 DeepSeek 时，程序仍会在输出达到 token 上限后依次切换低思考、更大额度和去摘要降级判断。
- Jev 和 DeepSeek 的远程断开、连接重置及常见 HTTP 临时错误都会自动退避重试；多次重试仍失败才进入人工复核或混合模式安全回退。
- AI 存疑复核窗口可保存草稿；误关后重新打开会恢复勾选。去重组的核查选择逐组保存到当前项目。
- 导入、词汇规范和去重在本机完成，不调用文献数据库 API；原始导出文件不会被修改。英文关键词的自动合并是词形规则，不理解语义；预览中可检查识别分组，也可关闭自动合并或在 JSON 中设置 `autoKeywordExclusions`。

## 运行环境

- 当前源码版需要 Windows、Python 3.10+ 和 Node.js；先运行 `python -m pip install -r requirements.txt` 安装文件拖放和图表组件。
- 首次构建内置 VOS 窗口时，在 `vosviewer_frontend` 目录运行 `npm ci`、`npm run build`；桌面窗口依赖系统 WebView2 Runtime。发布 EXE 已内置构建后的 VOSviewer Online 页面和 JavaScript 依赖许可文本。
- 旧版 `.xls` 解析使用随源码附带的 xlrd 2.0.2（BSD 许可），无需额外安装。
- 生成 Excel 需要 `@oai/artifact-tool`；在 Codex Desktop 工作区中会自动使用随附运行库。
- BAT 会优先使用程序目录下的 `runtime\python\python.exe`，因此后续可连同便携运行库或打包版一起分发。
- `release\WOS文献筛选工具.exe` 是便携单文件版，已经内置 Python、Node.js 和工作簿运行库；目标电脑无需另行安装这些组件。
