# Mannul-dedup

一款用于多数据库文献题录整理、去重、主题筛选和文献计量绘图的 Windows 桌面工具。各项目独立保存题录、核查结果和图谱设置；导入时按文件内容自动识别来源，无需预先指定数据库。

> 当前版本：1.22.0。项目仍在持续开发；跨数据库格式转换后的文件，建议在目标软件中抽样核对。

## 主要功能

- **导入与独立合并**：支持拖入多个题录文件，显示每个文件及各数据库的成功、失败数量。可选择“仅转换格式并合并”，保留重复题录和原始词语，不运行去重或词汇合并。
- **去重**：提供快速、期刊、严格、宽松四种预设；可逐组核查后统一去重，也可一键去重。自动去重优先保留 WoS 记录，遇到同组 DOI 冲突时保留整组。支持年份范围和跳过去重。
- **词汇规范**：分别核查国家、机构、作者、期刊、关键词的合并规则，支持搜索、编辑及双列制表符 TXT 导入导出。国家、机构、作者、期刊的已应用规则可跨项目复用；关键词规则保留在当前项目。可用 DeepSeek 分析当前选中的类别，建议仍应人工核查。
- **主题筛选**：可使用 TypeSafe Jev、DeepSeek，或 Jev 初筛加 DeepSeek 复核；保留人工复核、缓存、失败记录和审核日志。
- **绘图与图谱**：提供年度发文趋势、发文量和被引量排名、关键词排名，以及可调参数的 VOS 图谱。内置窗口支持网络与时间视图、节点筛选和编辑；可导出图谱 JSON、VOS 地图与网络文件、图片，也可将文件交给另装的 VOSviewer Desktop。

## 支持的输入

程序依据**内容**识别来源，扩展名本身不决定数据库。已实现的导入类型包括：

| 来源 | 常见格式 |
| --- | --- |
| Web of Science | 标签式 TXT、表格式 TXT、旧版 XLS、BibTeX、RIS |
| Scopus | RIS、纯文本、BibTeX、CSV |
| PubMed | 完整题录 TXT / NBIB、CSV |
| ScienceDirect | RIS、含 RIS 记录的 TXT |
| 中文数据库 / RefWorks | RefWorks TXT |

仅含 PMID 编号的 TXT 不含题名和摘要，不能单独用于主题筛选。无法识别的文件会显示导入错误。不同平台及导出选项可能改变字段结构，请先检查导入预览中的成功数、失败数与题录字段。

## 快速开始

### 源码运行

环境：Windows、Python 3.10 或更高版本；内置 VOS 窗口的前端构建另需 Node.js 和系统 WebView2 Runtime。

```powershell
python -m pip install -r requirements.txt
cd vosviewer_frontend
npm ci
npm run build
cd ..
python main.py
```

也可在安装 Python 依赖后双击 `启动文献筛选工具.bat`。不使用 VOS 图谱时，前端构建可暂缓。Excel 工作簿导出还依赖 `@oai/artifact-tool`；当前打包脚本使用 Codex Desktop 的随附运行库，普通 Python 环境不会仅凭 `requirements.txt` 获得这项依赖。

### 典型工作流程

1. 新建项目，把题录文件或文件夹拖入“文献工作区”。查看文件清单、来源统计和导入预览。
2. 根据需要编辑词汇合并规则并点击“应用合并到项目”。若只想汇总原始记录，使用“仅转换格式并合并”；若希望保留全部记录后直接绘图，可在项目中选择“跳过去重”。
3. 需要去重时设定年份和预设，查找候选组，逐组核查后统一去重；也可一键处理并检查排除数量。
4. 导出基础结果，或进入“筛选与导出”执行 AI 主题筛选。
5. 在“发文趋势与排名”或“VOS 图谱”中检查数据、调整图形并导出。

四个去重预设的字段组合来自旧版 BibNexus 前端资源；原版 Rust 匹配函数未恢复，因此候选数量不保证与旧版逐条一致。去重前请保留原始数据库导出文件。

## API Key 与本地数据

基础导入、去重、词汇规则和绘图可离线运行。使用 AI 时，在项目根目录放置以下文件，**每个文件第一行只填对应的 Key**：

| 服务 | Key 文件 | 环境变量 |
| --- | --- | --- |
| TypeSafe Jev | `typesafe_api_key.txt` | `TYPESAFE_API_KEY` |
| DeepSeek | `api_key.txt` | `DEEPSEEK_API_KEY` |

默认混合筛选模式需要两套 Key；DeepSeek 词汇建议只需 DeepSeek Key。API 调用可能产生费用。题录文件、项目数据、导出结果、缓存和 Key 文件均不纳入 Git 版本库。导入、规范化和去重在本机运行；AI 主题筛选与词汇建议会将相应字段发送给所选服务。

## 导出与保存

- 基础去重结果：保存位置可选，默认文件名 `download_YYMMDDHHmm.txt`，采用 WoS 风格纯文本结构。
- AI 筛选：结果通常写入 `output/YYMMDDHHmm/`，包含筛选工作簿、相关题录 TXT、审核日志及失败记录；同分钟重复导出会添加序号以免覆盖。
- 图表：PNG 图片与绘图数据 CSV 可分别选择保存位置。
- VOS：图谱 JSON、地图 TXT、网络 TXT 与图片；已保存的旧图谱是快照，修改词汇规则后需重新生成。
- 合并词：无表头的 TXT，每行依次为“保留词、制表符、合并词”；可选择当前文件合并词或全部合并词。

跨数据库转换导出为 WoS 风格 TXT 后，仍应在 VOSviewer、CiteSpace 等目标软件中抽样验证字段和记录数，尤其是引用、机构和参考文献字段。
